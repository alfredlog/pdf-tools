    Mode d’emploi : Filigrane

    1. Choisir un PDF

      Sélectionnez le PDF qui doit recevoir un filigrane.

    2. Saisir le texte

      Tapez le texte, ex. « BROUILLON » ou « Uniquement pour ma candidature chez X ».

    3. Ajuster l’apparence

      Choisissez disposition, opacité, taille et couleur.

    4. Enregistrer

      Cliquez sur « Ajouter le filigrane » et téléchargez le PDF.

    Questions fréquentes

    Peut-on retirer le filigrane ?

    Le filigrane est écrit dans la page sous forme de texte. Un logiciel spécialisé pourrait le retirer – pour une vraie protection, combinez-le avec « Protéger un PDF ».

    Les accents sont-ils pris en charge ?

    Oui, les lettres latines avec accents comme é, è, ç ou à s’affichent correctement.

    Mon PDF est-il envoyé ?

    Non, le filigrane est ajouté dans votre navigateur.
